# Proyek OpenCV FatchurR

Deskripsi singkat tentang proyek ini.

## Tugas
1. Tugas 1: Coba untuk mengubah gambar (misalnya mengubah ukuran atau rotasi)
sebelum menyimpannya.
2. Tugas 2: Modifikasi kode video sehingga hanya menampilkan sebagian frame atau
menambahkan efek tertentu pada setiap frame sebelum disimpan.

## Cara Menjalankan

Run file tugas1.py atau tugas2.py. untuk file kode asli tidak saya hapus, filenya berada di opencv_1/2.py
